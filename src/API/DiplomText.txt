Milliy Chat Dasturini ishlab chiqish

Kirish
Milliy chat dasturi - bu foydalanuvchilarga tezkor xabar almashish, guruhdagi muloqot va ma'lumot almashish imkonini beruvchi veb-ilova bo‘lib, u Telegramga o‘xshash interfeys va asosiy funktsiyalarni ta'minlaydi. Ushbu loyiha foydalanuvchilarga o‘zaro xabar yuborish, chat tarixini ko‘rish va server tomoni orqali muloqotni boshqarish imkoniyatini beradi.

Asosiy maqsad
Ushbu diplom ishi orqali milliy chat dasturining dizayni, arxitekturasi, ishlash mexanizmi va amaliy qo‘llanilishi ko‘rib chiqiladi. Loyihaning asosiy maqsadi foydalanuvchilarga qulay va tezkor xabar almashish muhiti yaratish, serverda xabarlarni saqlash va API orqali ulanish imkonini ta’minlashdan iborat.

Loyiha maqsadlari
1. Telegramga o‘xshash interaktiv chat ilovasini yaratish.
2. Foydalanuvchilar o‘rtasida xabar yuborish va ko‘rish imkoniyatini ta’minlash.
3. ASP.NET Core Web API orqali backend xizmatini yaratish.
4. Loyihani ishlab chiqish, ishga tushirish va sinovdan o‘tkazish.

Texnologiyalar
- ASP.NET Core Web API
- C# dasturlash tili
- Swagger/OpenAPI
- REST API
- JSON format
- HTML, CSS va JavaScript

Loyiha tuzilishi
Dastur quyidagi bo‘limlardan iborat bo‘ladi:
- Foydalanuvchi xabarlari qabul qilinadigan controller.
- Xabarlarni saqlash va qayta olish logikasi.
- Model va so‘rov/jo‘natish formatlari.
- Veb interfeys orqali API bilan aloqani ta’minlovchi frontend qismi.

Xulosa
Milliy chat dasturi zamonaviy muloqot vositalariga o‘xshash, lekin mahalliy talablar va amaliy ehtiyojlar asosida yaratilgan yechim hisoblanadi. Ushbu loyiha orqali o‘zbek tilida ish ko‘rish imkoniyatiga ega bo‘lgan chat ilovasi ishlab chiqish mumkin.
